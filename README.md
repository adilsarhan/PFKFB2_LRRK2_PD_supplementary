Supplementary Files for the PFKFB2–LRRK2 Parkinsonian Substantia Nigra Study

This repository contains the supplementary tables associated with the manuscript:

Single-Nucleus Phosphatome Rewiring and Phosphoproteomics Reveal PFKFB2 as an LRRK2-Linked Metabolic Node in Human Parkinsonian Substantia Nigra

Overview

This study investigates phosphatome remodeling in human Parkinsonian substantia nigra and identifies PFKFB2 as an LRRK2-linked metabolic node. The analysis integrates sample-level pseudobulk phosphatome profiling, differential co-expression rewiring, single-nucleus PFKFB2 cell-state analysis, paired donor-pseudobulk validation, phosphosite prioritization, kinase–peptide docking and LRRK2 phosphoproteomic interrogation.

File: Supplementary_Table_S3.xlsx

Supplementary Table S4

File: Supplementary_Table_S4.xlsx

Contains PFKFB2-positive versus PFKFB2-negative differential-expression signatures and disease-versus-control state signatures across selected disease-remodeled cell-type contexts.

Supplementary Table S5

File: Supplementary_Table_S5.xlsx

Contains the paired donor-pseudobulk validation of the PFKFB2-positive versus PFKFB2-negative transcriptional program in PDD microglia, including gene-level differential-expression results, signature-level analyses, pathway-category summaries and primary and stringent donor-eligibility analyses.

File: Supplementary_Table_S7.xlsx

Supplementary Table S8

File: Supplementary_Table_S8.xlsx

Contains LRRK2 phosphoproteomic curation, inhibitor-response summaries, spectrum-level validation and fragment-ion annotation supporting the conserved human PFKFB2 Ser483/mouse Pfkfb2 Ser486 region.
