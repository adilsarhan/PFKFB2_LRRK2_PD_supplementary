Supplementary files for the PFKFB2–LRRK2 Parkinsonian substantia nigra study

This repository contains supplementary tables associated with the manuscript:

Single-nucleus phosphatome rewiring and phosphoproteomics reveal PFKFB2 as an LRRK2-linked metabolic node in human Parkinsonian substantia nigra

Overview

This study investigates phosphatome remodeling in human Parkinsonian substantia nigra and identifies PFKFB2 as an LRRK2-linked metabolic node. The analysis integrates sample-level pseudobulk phosphatome profiling, differential co-expression rewiring, single-nucleus PFKFB2 cell-state analysis, phosphosite prioritization, kinase–peptide docking summaries and public LRRK2 phosphoproteomic interrogation.

Repository contents

Supplementary Table S1

File: Supplementary_Table_S1.xlsx

Contains the phosphatome-associated gene panel, family annotations, pseudobulk differential-expression analysis, co-expression matrix, co-expression modules and family-level summaries.

Supplementary Table S2

File: Supplementary_Table_S2.xlsx

Contains differential phosphatome rewiring results, gene-level rewiring metrics, integrated candidate-prioritization scores and expression summaries for top-ranked phosphatome hubs.

Supplementary Table S3

File: Supplementary_Table_S3.xlsx

Contains cell-type and disease-stratified PFKFB2 expression summaries across the human substantia nigra single-nucleus atlas.

Supplementary Table S4

File: Supplementary_Table_S4.xlsx

Contains PFKFB2-positive versus PFKFB2-negative differential-expression signatures and disease-versus-control state signatures across selected disease-remodeled cell-type contexts.

Supplementary Table S5

File: Supplementary_Table_S5.xlsx

Contains PFKFB2 sequence annotation, C-terminal phosphosite mapping, manual motif scoring, GPS kinase-specific phosphorylation predictions, integrated phosphosite prioritization and AlphaFold pLDDT summaries.

Supplementary Table S6

File: Supplementary_Table_S6.xlsx

Contains kinase–peptide docking model inventories, HADDOCK3 scoring, contact-density summaries, restrained-groove contacts and central phosphosite geometry measurements.

Supplementary Table S7

File: Supplementary_Table_S7.xlsx

Contains public LRRK2 phosphoproteomic curation, inhibitor-response summaries, spectrum-level validation and fragment-ion annotation supporting the conserved PFKFB2/Pfkfb2 Ser483/Ser486 region.

Data sources

The analyses used publicly available datasets and resources, including:

* Human substantia nigra single-nucleus RNA-seq dataset: GSE184950
* LRRK2 phosphoproteomic dataset: PXD003071
* Public supplementary phosphoproteomic data from Luerman et al. (2014)
* UniProt
* AlphaFold Protein Structure Database
* RCSB Protein Data Bank
* STRING

Large raw datasets are not included in this repository and should be obtained directly from GEO, PRIDE or the corresponding source publications.
